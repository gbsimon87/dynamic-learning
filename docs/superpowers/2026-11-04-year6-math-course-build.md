## Boundaries and review

- All Year 6 statutory bullets are mapped. There is no cross-year split to invent for Maths.
- No secondary-school extensions: no fraction-by-fraction division, simultaneous-equation methods, formal algebraic proof, circle area/circumference formulae, probability or significant-figure rounding.
- Non-statutory speed calculations and optional extensions are outside this course. SATs timing and test simulation are outside scope.
- Drawing with ruler/protractor, making physical nets and constructing graphs need practical follow-up. Screen activities will practise construction decisions and use interactive drawing/plotting where supported; these cannot certify physical tool use.
- Illustrations and worked examples follow Year 5 Maths. Use fraction models, place-value tables, number lines, written-method layouts, ratio bars, grids, graphs and labelled geometry where they teach the question.
- Pilot: complete Number – number and place value (four topics, sixteen challenges), including lessons, pictures, bank tests and a playthrough. Pause for owner trial before remaining strands.
- Register with `countsTowardYear: false`; preserve existing IDs, stored progress and award membership.

## Pilot trial

1. Run `npm run dev` and open the Vite URL printed in the terminal.
2. Sign in locally if needed and select a child profile. Choose Curriculum Mode,
   Year 6, Maths, then **Number – number and place value**.
3. Try all four challenges in each of the four topics. Each opens with Bix's
   tips and an example; press **Let's go!** to start.
4. Check ten-million charts, zero placeholders, halfway rounding, negative
   temperatures across zero, and contextual population/count questions.
5. Make two wrong attempts to see the hint; correct the answer and finish five
   questions. Replay a completed challenge; try sorting and ordering on touch.
6. Try light/dark themes and a narrow phone viewport. Other strands should show
   their topics as unavailable. Saved learner progress must remain intact.

The timer is paused when handing the pilot to the owner. It will resume after
feedback; final stop/report and measured token usage belong after the remaining
strands are built and verified.
